Linux commando's

Gemaakt door Damian Jeucken

Op deze pagina staan Linux commando's die handig zijn voor DevOps. Bij elk commando staat wat het doet en een voorbeeld.

Navigeren in mappen

pwd

Laat zien in welke map je op dit moment zit.

Voorbeeld: pwd

ls

Laat de bestanden en mappen in de huidige map zien.

Voorbeeld: ls

Met ls -l zie je meer informatie. Met ls -a zie je ook verborgen bestanden.

cd

Hiermee ga je naar een andere map.

Voorbeeld: cd /var/log

Met cd .. ga je een map omhoog. Met cd ~ ga je naar je persoonlijke map.

tree

Laat mappen en bestanden zien in een boomstructuur.

Voorbeeld: tree

Dit programma moet soms eerst worden geïnstalleerd.

Bestanden en mappen beheren

touch

Maakt een leeg bestand als het nog niet bestaat. Als het al bestaat, worden de tijdstempels aangepast.

Voorbeeld: touch oefening.txt

mkdir

Maakt een nieuwe map.

Voorbeeld: mkdir school

rm

Verwijdert een bestand.

Voorbeeld: rm oefening.txt

Met rm -r school verwijder je de map school met de inhoud. Let op: dit gaat niet naar de prullenbak.

cp

Maakt een kopie van een bestand.

Voorbeeld: cp oefening.txt kopie.txt

mv

Verplaatst een bestand of geeft het een andere naam.

Andere naam geven: mv oefening.txt huiswerk.txt

Verplaatsen naar een bestaande map: mv huiswerk.txt school/

Tekst bekijken en bewerken

nano

Opent een teksteditor in de terminal. Hiermee kun je tekst schrijven en aanpassen.

Voorbeeld: nano oefening.txt

Opslaan doe je met Ctrl + O en daarna Enter. Afsluiten doe je met Ctrl + X.

cat

Laat de volledige inhoud van een tekstbestand in de terminal zien.

Voorbeeld: cat oefening.txt

less

Hiermee bekijk je een tekstbestand en kun je door de tekst bladeren. Dit is handig bij lange bestanden.

Voorbeeld: less oefening.txt

Gebruik de pijltjestoetsen om te bladeren en druk op q om te stoppen.

head

Laat standaard de eerste 10 regels van een bestand zien.

Voorbeeld: head oefening.txt

Alleen de eerste 5 regels: head -n 5 oefening.txt

tail

Laat standaard de laatste 10 regels van een bestand zien.

Voorbeeld: tail oefening.txt

Alleen de laatste 5 regels: tail -n 5 oefening.txt

Hulp en handige commando's

man

Opent de handleiding van een commando.

Voorbeeld: man ls

Druk op q om de handleiding te sluiten.

clear

Maakt het zichtbare terminalscherm leeg.

Voorbeeld: clear

whoami

Laat zien met welke gebruikersnaam je werkt.

Voorbeeld: whoami

sudo

Voert een commando uit met beheerdersrechten als je daarvoor toestemming hebt.

Voorbeeld: sudo apt update

Dit voorbeeld werkt de lijst met beschikbare softwarepakketten bij in Ubuntu.

Git en SSH

Git houdt wijzigingen in bestanden bij. GitHub is een website waar je Git-projecten online kunt bewaren en samen kunt werken. Met SSH kun je veilig verbinding maken met een andere computer.

git init

Start een Git-repository in de huidige map.

Voorbeeld: git init

git status

Laat zien welke bestanden veranderd zijn en welke klaarstaan voor een commit.

Voorbeeld: git status

git add

Zet wijzigingen in een bestand klaar voor de volgende commit.

Voorbeeld: git add index.html

git commit

Slaat de klaargezette wijzigingen op in de lokale Git-geschiedenis met een bericht erbij.

Voorbeeld: git commit -m "HTML pagina toegevoegd"

ssh

Maakt een beveiligde verbinding met een andere computer waarop een SSH-server draait.

Voorbeeld: ssh -p 2222 damian-vm@localhost

Met dit commando maak ik vanuit Windows CMD verbinding met mijn Linux-VM. VMware stuurt poort 2222 door naar poort 22 van de VM.
